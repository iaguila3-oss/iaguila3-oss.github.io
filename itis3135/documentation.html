Introduction

JavaScript is a lightweight, interpreted programming language most commonly used to add interactivity to web pages.

It runs in the browser and, with Node.js, on the server as well.

This guide covers the fundamentals every beginner should know.

Variables

Variables store data values. You can declare them with let, const, or var.

let allows reassignment, while const does not.

Example:

let age = 25;

Choosing the right declaration keyword helps prevent bugs.

Functions

Functions are reusable blocks of code that perform a specific task.

They can be declared using the function keyword or as arrow functions.

function greet() { return "Hello"; }

Arrow function example:

const greet = () => "Hello";

Functions can accept parameters and return values.

Arrays

Arrays store ordered collections of values.

const fruits = ["apple", "banana", "cherry"];

Common array methods include:

  • push() – adds an item to the end
  • pop() – removes the last item
  • map() – transforms each item

Arrays are zero-indexed, meaning the first item is at index 0.

Loops

Loops let you repeat a block of code multiple times.

Common loop types include:

  • for loops
  • while loops
for (let i = 0; i < 5; i++) { console.log(i); }

Loops are essential for processing arrays and repeating tasks.

Objects

Objects store data as key-value pairs.

const person = { name: "Alex", age: 30 };

You can access values using dot notation or bracket notation.

  • person.name
  • person["age"]

Objects are one of the most fundamental data structures in JavaScript.
